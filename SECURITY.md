# Security Policy

If you believe you've found a security vulnerability in LogLens, please **do not open a public issue**.

Instead, email **support@veryation.com** with the details. Please include steps to reproduce and the relevant version and environment information.

We'll acknowledge your report as quickly as we can and keep you updated as we investigate. We ask that you give us a reasonable opportunity to address the issue before any public disclosure.

Thank you for helping keep LogLens and its users safe.
