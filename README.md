# LogLens

**Issue tracker & feature requests for [LogLens](https://apps.veryation.com/loglens)** — a fast large-file log viewer for JetBrains IDEs and Visual Studio Code, by [Veryation](https://apps.veryation.com).

LogLens is a commercial plugin and its source is not public. **This repository is the public place to report bugs and request features**, so fixes and improvements benefit everyone.

## Report a bug or request a feature

- Open a **[new issue](../../issues/new/choose)** and pick **Bug report** or **Feature request**.
- **Search [existing issues](../../issues) first** — if yours is already there, add a 👍 or a comment instead of opening a duplicate. Reactions help us prioritize.

## Getting support

- **Bugs & feature requests:** here, via GitHub Issues.
- **Licensing, billing, security, or anything private:** email **support@veryation.com**.

We monitor issues and support email during **US business hours (Pacific)** and aim to respond within **2 business days for critical issues and 5 business days otherwise**. These are best-effort targets, not a contractual SLA — we'd rather set expectations we can consistently meet than over-promise.

> ⚠️ **Please don't post license keys, credentials, or private log contents** in public issues. Redact sensitive data from any samples or screenshots.

## Security

Found a security vulnerability? Please **don't open a public issue** — email **support@veryation.com**. See [SECURITY.md](SECURITY.md).
